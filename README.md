# Module-End-Assignment-Data-Cleaning-Analysis-Visualization-with-Excel
The four datasets were imported, organized into Excel Tables and checked for duplicate records, missing values, inconsistent formatting and invalid references. 
Customer names and country values were standardized, and missing numerical values were investigated. 
Recoverable missing transaction amounts were recalculated using Quantity × Unit_Price × (1 − Discount). The Sub_Category column was removed as required by the assignment.
XLOOKUP was used to combine customer, product and store information with the main sales transaction table. 

Excel functions including SUM, AVERAGE, IF, COUNTIF and TEXT were applied to calculate sales metrics, classify transactions, and count payment methods. XLOOKUP was used to retrieve related information from the dimension tables. Descriptive statistics, including mean, median, mode, standard deviation, minimum and maximum, were used to examine numerical sales data.

Dashboard is created and summarized the key findings in the pdf file.
